Etapa 2 • CRISP-DM & Algoritmo Estatístico

Z-Score Adaptativo em Janelas Móveis e Orquestração n8n

1. Limites Dinâmicos com Rolling Window

Cálculo contínuo de média móvel e desvio padrão em janela móvel de 24 horas para acomodar a sazonalidade horária natural do e-commerce.

2. Gatilho de Alerta e Persistência

Classificação de anomalia crítica quando |Z| ≥ 2.5 persistente em 2 intervalos consecutivos para eliminar ruídos transitórios.

Motor Estatístico Python (anomaly_detector.py): Python 3.10 • NumPy 
# anomaly_detector.py: Detecção Vetorial de Z-Score
import numpy as np
import pandas as pd

def detectar_anomalia_transacional(df_historico, limiar_zscore=2.5):
    df_historico['media_movel'] = df_historico['pedidos'].rolling(window=24, min_periods=6).mean()
    df_historico['std_movel'] = df_historico['pedidos'].rolling(window=24, min_periods=6).std()
    
    df_historico['z_score'] = (
        (df_historico['pedidos'] - df_historico['media_movel']) / 
        df_historico['std_movel'].replace(0, np.nan)
    ).fillna(0)
    
    df_historico['is_anomaly'] = df_historico['z_score'].abs() >= limiar_zscore
    return df_historico[df_historico['is_anomaly']]
